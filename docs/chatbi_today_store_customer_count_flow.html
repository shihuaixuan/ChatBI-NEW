一、当前行为的关键事实

默认时间维度 #276 存在，但本次没有绑定首次检索时指标槽位仍为 ambiguous，bind_default_time_dimensions() 看到 selected_metrics=[]，直接返回原 bundle。澄清选择 #272 后只执行 apply_semantic_clarification() 和 apply_decision_to_semantic_payload()，没有再次调用默认时间维度绑定。
第一次编译失败与后续失败是两个不同状态澄清后 scope 一度为 resolved，但 filters=[]，因此返回 time_filter_mismatch。随后模型再次调用 search_semantic_assets({})，新的 ambiguous 结果被状态投影直接覆盖进去，后续编译才返回 semantic_decision_not_executable。
4000 字符只处理模型 ObservationToolResult.data、业务 metadata 和 state patch 在摘要前处理；编译读取 semantic_scope，不是读取 4000 字符文本。本次时间资产缺失在完整 payload 中已经存在。
